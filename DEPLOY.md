# Как опубликовать сайт на GitHub Pages

1. Открой репозиторий `atlas-portfolio`.
2. Удали старые файлы или замени их новыми.
3. Загрузи содержимое этой папки в корень репозитория.
4. Важно: `index.html` должен лежать сразу в корне репозитория.
5. Открой `Settings → Pages`.
6. Выбери `Deploy from a branch`.
7. Branch: `main`.
8. Folder: `/root`.
9. Нажми `Save`.
